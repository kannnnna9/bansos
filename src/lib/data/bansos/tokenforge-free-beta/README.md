# ✅ TokenForge Free Beta - Kredit Promosi dan Akses GLM-5.2 & Grok 4.5

**Provider:** TokenForge

TokenForge adalah gateway AI yang kompatibel dengan OpenAI dan sedang membuka controlled free beta. Halaman resminya menyebut akun baru menerima kredit promosi tanpa checkout atau penagihan aktif. Pricing Explorer saat ini mencantumkan 100 request per hari, 100.000 token per hari, serta akses GLM-5.2 dan Grok 4.5. Namun dokumentasi request admission menyebut platform tidak menerapkan batas harian, per menit, atau konkuren; karena ada perbedaan keterangan resmi, kuota aktual perlu dicek di dashboard sebelum digunakan. Tarif kredit mengikuti rate upstream yang ditautkan ditambah platform charge transparan 3,5 kali.

> **Status:** Aktif

⏰ **Info Waktu:** Controlled free beta tanpa tanggal akhir yang diumumkan; halaman pricing dan dokumentasi resmi berbeda dalam menjelaskan batas request, sehingga kuota aktual perlu dikonfirmasi sebelum digunakan

## Keuntungan

- Controlled free beta dengan kredit promosi untuk akun baru; tidak ada checkout maupun penagihan aktif
- Pricing Explorer saat ini mencantumkan 100 request per hari dan 100.000 token per hari; cek dashboard karena dokumentasi resmi juga menyebut tidak ada batas platform
- Akses model GLM-5.2 dan Grok 4.5 lewat satu endpoint kompatibel OpenAI
- Katalog model teks yang dipublikasikan di halaman resmi, dengan ketersediaan yang dapat berubah
- Tarif kredit per rute mengikuti tarif upstream resmi yang ditautkan plus platform charge transparan 3,5 kali

## Persyaratan

- Sign-in wajib memakai akun GitHub karena itu satu-satunya metode login
- Akun GitHub minimal berumur 14 hari dan memakai alamat email permanen yang sudah terverifikasi
- Pricing Explorer mencantumkan 100 request dan 100.000 token per hari, tetapi dokumentasi request admission menyebut tidak ada batas platform; ikuti keterangan dashboard terbaru
