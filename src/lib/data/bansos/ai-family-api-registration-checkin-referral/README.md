# ✅ AI-Family API — Pendaftaran Terbuka dan Check-in

**Provider:** AI-Family

AI-Family adalah gateway API berbasis New API. Status publik pada 10 September 2026 menunjukkan pendaftaran akun baru serta registrasi password aktif, verifikasi email diaktifkan, dan fitur check-in tersedia. Situs juga mengumumkan bahwa akun wajib mengaktifkan 2FA. Tautan ini menyertakan kode afiliasi S6g5, tetapi sumber publik tidak menyebut nominal kredit atau bonus referral sehingga tidak diklaim sebagai benefit.

> **Status:** Aktif

⏰ **Info Waktu:** Pendaftaran dan check-in diverifikasi aktif dari endpoint status publik pada 10 September 2026; kuota serta kebijakan dapat berubah

## Keuntungan

- Pendaftaran akun baru melalui email dan password
- Fitur check-in tersedia di dashboard
- Akses endpoint API utama https://api.aifamily.vip/v1 setelah membuat akun dan API key

## Persyaratan

- Mendaftar dengan email dan password
- Menyelesaikan verifikasi email
- Mengaktifkan 2FA pada pengaturan keamanan akun
- Gunakan tautan referral bila ingin mendukung kontributor
